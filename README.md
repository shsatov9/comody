# comody

チラシの特売品から献立を決めて、食べたものを記録するアプリ。

コモディイイダのチラシを取り込むところから始めるので `comody`。

## なぜ作るか

献立を決めるとき、知りたいことが2つある。**今日は何が安いか**と、**それを食べて
栄養は足りるか**。前者はチラシに、後者は記録に載っているが、両方を同時に見る
手段が無い。家計簿アプリは値段しか見ないし、栄養記録アプリは値段を見ない。

このアプリは、チラシから読み取った価格と、食べたものの栄養を、同じ1本の記録に
繋ぐ。「先週の食費は 8,400 円で、葉酸は目標の 7 割だった」が1画面で分かる状態を
目指す。
